Game Rules:

- The board size is m × m.
- Two players alternate turns.
- On each move, a player fills one empty cell.
- A player may place either 0 or 1 on any move.
- Both players have access to both symbols.
- A winning row has length 3.
- A winning row can be horizontal, vertical, or diagonal.
- If a player creates a winning row, that player LOSES.
- The goal is to force the opponent to create a winning row.

Based on observed behavior, the game does not appear to allow a draw.
